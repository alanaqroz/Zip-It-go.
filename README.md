# ✈️ Zip It Go

O **Zip It Go** é um aplicativo inteligente que facilita o planejamento da sua bagagem. A partir de informações como **destino, clima, duração e tipo de viagem**, o aplicativo gera automaticamente uma lista personalizada de itens essenciais, tornando a preparação da viagem mais prática, rápida e organizada.

## 📱 Sobre o Projeto

Viajar envolve diversas etapas de planejamento, e uma das mais comuns é decidir o que levar na mala. O Zip It Go foi desenvolvido para eliminar esse problema, reunindo todo o planejamento pré-viagem em uma única plataforma.

Com listas inteligentes e personalizadas, o aplicativo reduz a chance de esquecer itens importantes e economiza tempo na organização da bagagem.

## ✨ Funcionalidades

- 🧳 Geração automática de listas de bagagem
- 🌤️ Sugestões baseadas no clima do destino
- 📍 Personalização conforme o destino da viagem
- 📅 Recomendações de acordo com a duração da viagem
- 🏖️ Adaptação ao tipo de viagem (lazer, negócios, aventura, etc.)
- ✅ Checklist interativo para acompanhar os itens já separados
- ✏️ Adição, edição e remoção de itens personalizados

## 🚀 Como Funciona

1. Informe o destino da viagem.
2. Selecione a duração da viagem.
3. Escolha o tipo de viagem.
4. O aplicativo analisa as informações.
5. Uma lista de bagagem personalizada é gerada automaticamente.
6. Revise, personalize e acompanhe seu checklist antes da viagem.

## 🎯 Objetivo

O principal objetivo do Zip It Go é tornar o planejamento da bagagem simples e eficiente, oferecendo recomendações inteligentes para que o usuário viaje com tranquilidade, sem esquecer itens importantes.
