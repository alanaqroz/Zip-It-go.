# Zip It! — Landing Page

Landing page do app **Zip It!**, um organizador de malas inteligente para iOS.

## Estrutura

```
zipit-landing/
├── index.html   # Estrutura HTML
├── styles.css   # Estilos e responsividade
├── script.js    # Internacionalização (EN/PT) e animações
└── README.md
```

## Funcionalidades

- **Bilíngue (EN / PT)** — detecção automática pelo idioma do navegador, com toggle manual
- **"Coming Soon"** — badge e seção CTA indicando que o app ainda não foi lançado
- **Animações fade-in** — elementos aparecem suavemente ao rolar a página
- **Mockup interativo** — simulação de tela do app flutuando no hero
- **Totalmente responsivo** — adaptado para desktop, tablet e mobile

## Seções

| Seção | Descrição |
|---|---|
| Nav | Logo, toggle de idioma e botão "Coming Soon" |
| Hero | Título, subtítulo, CTA e mockup do app |
| Features | 6 cards com os principais recursos |
| How it works | Passo a passo em 4 etapas |
| Pricing | Planos Free, Monthly e Lifetime |
| CTA | Chamada final com badge "Launching Soon" |
| Footer | Links de privacidade, termos e contato |
